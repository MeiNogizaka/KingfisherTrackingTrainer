# カワセミ追尾トレーナー

飛んだり、ダイブしたりするカワセミを、家のモニタの前で追う練習をするためのジョークWebアプリです。

**遊んでみる:** https://meinogizaka.github.io/KingfisherTrackingTrainer/

モニタの大きさ、立つ位置、レンズの焦点距離を入れると、画面の中のカワセミが、その条件でファインダー越しに見える大きさや速さに近づきます。川へ行く前の素振り用です。露出もピントも、この子は合わせてくれません。

## 画面に何が出るか

水面の上にダイブポイントが10か所、枝が5か所あります。カワセミは枝で止まり、飛び出す前に顔とくちばしを着水方向へ向け、身体を沈めてから飛びます。着水すると少し沈んで、また枝へ戻ります。設定した確率で、ダイブ前の枝に戻ります。

ときどき、沈んだあと飛ばずに止まり直します。フェイントです。

軌道は3種類です。

- 止まり木＋ダイブ
- 水平飛行
- 上下飛行

背景は川辺と無地を切り替えられます。

## 合わせ方

1. モニタに実際に映っている横幅を、センチメートルで入れます。
2. 目からモニタまでの距離を入れます。
3. 本番で使うレンズと、今モニタを覗く練習用レンズの焦点距離を、35mm判換算のミリメートルで入れます。
4. 想定しているカワセミまでの距離、飛行速度、全長を入れます。
5. 「開始 / 再スタート」を押して、全画面にします。
6. 入力した距離だけモニタから離れて、練習レンズごしに追います。

「20 cm 基準線」を出して、ものさしで測った長さを「基準線の実測値」に入れると、画面上の縮尺が実測に合います。

パネルには、推定角速度、本番レンズの画面に対する横方向・縦方向の占有率、モニタ上のカワセミの全長が出ます。

設定はブラウザの中に保存されます。「設定値を初期化」で最初の値に戻ります。

## 操作

| 操作 | 動作 |
| --- | --- |
| スペース | 一時停止 / 再開 |
| R | 再スタート |
| F | 全画面 |
| 設定を隠す | 左上のパネルをしまう |

## 手元で開く

ビルドは要りません。[index.html](index.html) をブラウザで開いてください。[kingfisher_tracking_trainer.html](kingfisher_tracking_trainer.html) も同じ内容です。
